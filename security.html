Security Features Overview

NAATYA implements multiple client-side security measures to protect sensitive production data, scripts, and intellectual property. These features safeguard against unauthorized access, data theft, and content duplication.

Right-Click Disabled

Context menu is blocked across all pages to prevent users from accessing "Save As", "View Source", or "Inspect Element" through right-click actions.

Active
Copy/Cut Blocked

Clipboard operations (copy and cut) are intercepted and blocked to prevent unauthorized duplication of scripts, member details, and proprietary content.

Active
Developer Tools Blocked

Keyboard shortcuts for developer tools (F12, Ctrl+Shift+I, Ctrl+Shift+J, Ctrl+U) are intercepted and disabled to prevent code inspection.

Active
Blur on Tab Switch

When the user switches to another browser tab, the application content is hidden behind a blur overlay, preventing visual data leakage via screenshots or over-the-shoulder observation.

Active
Authentication Required

All dashboard pages require authentication. Unauthenticated users are redirected to the login page. Session management protects against unauthorized access.

Active
Input Sanitization

All user inputs are sanitized using HTML escaping to prevent XSS (Cross-Site Scripting) attacks. Dynamic content insertion uses safe DOM methods.
